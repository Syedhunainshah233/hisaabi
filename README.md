# Hisaabi

Easy Khata-style money ledger for Android: track what you gave (Diya) and got (Liya) for each person, with daily/weekly/monthly reports. All data stays on the phone.

- Kotlin + Jetpack Compose + Room
- English and Roman Urdu
- Emerald & Gold theme, dark mode, PIN lock
- PDF statements, WhatsApp reminders, CSV export

## Build

Every push to `main` builds a test APK with GitHub Actions (Actions tab → latest run → **Hisaabi-test-apk**).

Locally: open the folder in Android Studio, or run `./gradlew :app:assembleDebug`.
